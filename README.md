# 🥃 Iowa Liquor Sales Dashboard | Power BI

## 📌 Project Overview

The **Iowa Liquor Sales Dashboard** is an interactive Power BI report developed to analyze liquor sales data across Iowa. The dashboard transforms raw transactional data into meaningful business insights through data cleaning, modeling, DAX calculations, and interactive visualizations.

It helps identify sales trends, top-performing stores, product categories, and geographical sales distribution, enabling data-driven business decisions.

---

## 🎯 Project Objectives

- Analyze overall liquor sales performance
- Monitor sales trends over time
- Evaluate store performance
- Identify top-selling product categories
- Explore geographical sales distribution
- Build an interactive business intelligence dashboard
